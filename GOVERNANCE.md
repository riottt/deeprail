# Governance

DeepRail v0.16.8 is a public release. The Japanese Standard projection (DR-M01〜DR-M25) is the approved canonical projection; the English Standard projection is Preview.

The following require explicit approval by RIO AMADA:
- Public release
- Canonical promotion
- Stable Module ID changes
- Breaking schema changes
- License / trademark changes
- Governance model changes

Contributors may propose changes through evidence-backed diffs and tests. Public releases, canonical promotions, stable module changes, and license or trademark changes remain explicit human decisions owned by RIO AMADA.
