# 読書順 — 45章 + 終章

本書は、規範モジュールのID順には並べない。
読者が**森を見てから現場へ降り、AI駆動開発とHarnessの最深部まで潜り、最後にもう一度組織・経営・未来へ戻る**順序で構成する。

```text
MACRO
AI時代 / Human-AI Boundary / Strategy
        ↓
Organization / Transformation
        ↓
Demand / Customer / Work
        ↓
Human + AI Team Leadership
        ↓
Evaluation Trust / Delegation
        ↓
Software Engineering
        ↓
Delivery System / CI/CD
        ↓
Execution Harness
        ↓
Organization Engineering / Governance / Learning
        ↓
MACRO
Strategy / Future
```

## Part I. AIが働く時代を理解する — まず森を見る

1. **DeepRailとは何か — AIが働く組織を設計する**
2. **AIは「ツール」から「実行主体」へ変わる**
3. **人間とAIの役割境界は固定されない — 「人間にしかできない仕事」が書き換わり続ける**
4. **なぜAI導入は経営戦略になるのか — 仕事・人・権限・競争優位の再設計**
5. **AIと働く人間の心構え — 作業から委譲・評価・改善へ**
6. **強い会社と強いHarnessはなぜ似るのか — PurposeからExecutionまでをつなぐ**

## 終章. すべての人が「小さな組織」を率いる時代へ

AIへ仕事を任せる人は、目的を決め、仕事を分け、権限を与え、成果を評価し、例外を判断し、失敗から仕組みを改善する。
DeepRailはこの行為を単なるAI操作ではなく、**最小単位の組織運営**として捉える。

ただし、ここで「人間は永遠に経営だけをする」と固定しない。
AI自身もPlanning・Evaluation・Coordination・Strategy Option Designへ入り続ける。
HumanとAIの境界を守り続けても、Capabilityが変わればすぐ古くなる。**その時点で最も安全かつ強い責務配置へ、Evidenceを見ながら組織を更新し続ける。**
