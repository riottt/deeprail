# Authorship

**DeepRail Creator / Lead Author: RIO AMADA**

DeepRail is published as an integrated method, standard, workflow system, and runtime architecture under the DeepRail project.

The public repository is designed to stand on its own: Book explains the reasoning, Standard defines the rules, Workflows operationalize them, and Runtime / Evals / Adapters make them executable.

Third-party software names appear only where DeepRail directly integrates or interoperates with that software. Those integrations do not define DeepRail Core semantics. Any third-party code or assets introduced in the future must retain attribution required by their licenses.
