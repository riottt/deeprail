# DeepRail v0.16.8

DeepRail v0.16.8 is the public release of the DeepRail AI-native organization and engineering standard, workflow runtime, and evidence-gated operating system.

## Scope

- Japanese Standard projection: formal and canonical, including DR-M01〜DR-M25
- English Standard projection: Preview; normative module translation is planned for a later release
- Runtime communication and artifact output: Japanese and English
- Python: 3.10〜3.13

## Included

- Book, Docs, Diagnostic, Standard, Workflows, Runtime, Adapters, Evals, and examples
- Evidence-gated transitions, audit history, thin runtime adapters, and diagnostic flow
- Reproducible wheel, source distribution, ZIP archive, SHA256 checksum, and release manifest

## Verification

The release is gated by generation, repository checks, unit tests, package build, runtime release audit, documentation build, and public clone smoke testing. See [`CHANGELOG.md`](CHANGELOG.md) and [`SECURITY.md`](SECURITY.md) for project boundaries.
