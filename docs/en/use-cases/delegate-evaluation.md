# Delegating Evaluation to AI

Raise EA in stages.

```text
EA0 Human Evaluation
EA1 Shadow Evaluation
EA2 AI-First / Human Decision
EA3 Audited Autonomy
EA4 Policy-Governed Autonomy
```

Do not raise it because the AI is capable; raise it only after Evidence / Failure Detection / Rollback / Audit hold for that Work Class.
