# DeepRail Diagnostic — Start from Your Blocker

You do not need to read the 350,000-character Book first. Check your current blocker with 18 questions, then connect to the Book, Standard, and Workflows.

```bash
deeprail assess --questionnaire > answers.json
# fill each value in answers.json with 0-3
deeprail assess --answers answers.json --format md
```

Evaluation axes:
- Shared Reality
- Evidence
- Human Review
- Delegation
- Delivery System
- Reinvestment

This is not a maturity ranking that grades organizations. It is **navigation for finding what to design next**.
