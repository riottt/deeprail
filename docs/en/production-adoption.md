# Production Adoption Guide

Do not raise EA/A all at once in a production project.

1. `deeprail init --profile standard --adapter generic`
2. Choose one Work Class
3. Calibrate the Evidence Contract in Human-led / AI-assisted mode
4. Run Shadow Evaluation
5. Confirm Failure Detectability / Reversibility / Auditability
6. Change A / EA / S per Work Class
7. Return Human Intervention to Reinvestment
8. Roll delegation back when conditions weaken

DeepRail is not a maturity contest; it manages the conditions under which responsibility may be transferred.
