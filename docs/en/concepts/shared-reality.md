# Shared Reality

Shared Reality is not an artifact. It is the state in which humans and AI share sufficient common understanding of the Problem, Domain, Decisions, and Acceptance.

A Context Asset is information externalized to reproduce, verify, and reuse that state.

`Preparing Context Assets = Shared Reality achieved` is not true.

Related: [DR-M14](../../../standard/modules/DR-M14.en.md)
