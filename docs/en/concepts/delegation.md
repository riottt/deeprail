# Delegation / Dynamic Responsibility Boundary

DeepRail does not install a fixed notion of "human work" for the AI era. Per Work Class, responsibility is transferred based on Capability / Risk / Evidence Reliability / Failure Detectability / Reversibility / Permission / Accountability.
