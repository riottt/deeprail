# Align

**Workflow ID:** `deeprail-align`

## Purpose
Establish Shared Reality around the proposed shape, boundaries, decisions, and unknowns.

## Inputs
- shape artifact
- stakeholder feedback

## Outputs
- agreed understanding
- open decisions
- rejected assumptions

## Required Evidence
- explicit agreement or recorded unresolved decision

## Exit Condition
The accepted scope can be converted into an execution contract.

## Decision Rights
Decision owner approves semantic commitments.

## Failure / Return Path
- discover
- shape

## Next
- `specify`
- `decide`

## Runtime Language
Human-facing communication uses the resolved `communication_language`.
Human-readable generated artifacts use the resolved `artifact_output_language`.
Stable IDs, schema keys, code identifiers and machine enum values are not translated.
