# Standard Translation / Projection Contract

DeepRail has one Standard version and shared Stable Module IDs.

Japanese is the current primary authoring language. English is a first-class Preview Standard projection for v0.16.8 and is planned for a later formal projection review.

The v0.16.8 formal Standard projection is Japanese. A missing English module is a release failure only when English is declared part of the formal release scope.

Standard projection language is independent from runtime communication and artifact output language.

A runtime language change MUST NOT alter Standard projection status.
